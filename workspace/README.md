# Your agent's workspace

This directory belongs to YOUR agent, for THIS site. Sightkick never reads or
writes it, and skill updates never touch it. The skill instructs the agent
to keep its working context here so it compounds across sessions:

- `context.md` — the site, audience, positioning and product facts the agent
  has learned (so it stops re-asking).
- `log.md` — dated notes on what it changed and why.
- `hooks.md` — angles, framings and structures that scored well, worth
  reusing.

Feel free to edit any of these yourself — the agent treats them as shared
notes with you.
